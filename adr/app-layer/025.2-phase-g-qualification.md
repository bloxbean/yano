# ADR-025.2 Phase G — Qualification and final v1 freeze

## Status

Implemented and qualified on 2026-08-04, with two recorded deferrals that do
not touch the frozen wire/state contracts: the §18 measurement repeat on the
supported native runtime, and browser automation for the console (verified
manually against the packaged distribution).

## Qualification matrix

The JVM matrix ran green end to end: every touched module gate, the full
`:app:check`, the appchain-composite integration suite, and all four
distribution acceptance contracts. Closing the matrix surfaced and fixed a
stale packaged smoke gate that still pinned plugin API level 1 from before the
ADR-011 platform (`packagedJvmPluginCatalogSmoke`), which had masked the
distribution tier since that merge. A live three-node packaged-distribution
run (recorded in Phase F) exercised threshold-2 finality, governed direct-role
and two-organization approval flows, and cross-node record consistency.

## Scenario coverage

Newly added for this phase: a hostile crypto-workload test proving the
deterministic per-block work cap rejects excess evidence with
`ERROR_CRYPTO_WORK_EXCEEDED` and reopens at the next height; a per-deadline
bucket test proving one bucket saturates with `CAPACITY_EXCEEDED` while global
and per-policy capacity remain open; and a governed-workload conformance run
on both `mpf-blake2b256-v1` and `jmt-blake2b256-v1` in which interleaved open
and actor-signed direct-role commands replay byte-identically across three
independent runs with mid-workload restart and snapshot restore — the
framework's rollback semantics, since finalized app-chain blocks have no reorg
path and recovery is always snapshot-restore plus deterministic replay.

Already covered and verified in place: mismatched genesis/profile markers
(`CompositeStateMachineProfileMarkerTest`, `AuthenticatedMapStateMachineTest`)
and executable-artifact digest mismatch
(`CatalogAuthenticatedMapValidatorResolverTest` rejects a catalog closure
digest that differs from the genesis binding); invalid genesis-closure,
pending saturation, expiry reclamation, actor/key rotation, and statement
domain binding (role-workflow suites); STAGING proposal threshold cancellation,
expiry, malformed floods, and membership-change voiding — the
profile-governance rescue paths — in
`CompositeProfileGovernanceAdversarialTest`; and late join and catch-up at the
cluster level (`CompositeProfileGovernanceClusterIntegrationTest`) with
state-level equivalence guaranteed by the replay-determinism runs.
Membership-key rotation cannot strand governed administrators structurally:
direct and administrator evidence is authenticated by genesis-registered actor
keys, never member keys, which the member-policy rotation and governed
key-rotation tests exercise independently. Pruning and abrupt-crash atomicity
are commitment-backend and framework properties (bounded JMT version history
behind `oldest-provable`, per-block atomic write batches) rather than
authenticated-map surface; graceful close/reopen is exercised by every
conformance run.

## Proof bundles

All four bundle kinds now verify end to end against real merkle proofs, and
each carries an adversarial rejection: BASIC (payload substitution,
wrong-root, unrelated-key), DIRECT_ROLE (wrong-genesis, and a proven-but-stale
current pointer breaking the historical-currency claim), APPROVAL (a
fabricated `APPROVED` proposal below the two-distinct-organization clause is
rejected because the client re-derives clause satisfaction), and
ADMINISTRATOR_GOVERNANCE (a fabricated `ACTIVATED` mutation below the
authority threshold is rejected because the client re-derives the distinct
administrator threshold).

## Freeze review and v1 declaration

The Phase-A maxima remain frozen and enforced by construction: 32 evidence
items, 128 covered mutation indexes, the governed genesis/pending/deadline
capacity table in `GovernedAuthorizationLimitsV1` (lowerable by genesis, never
exceedable), and the deterministic crypto work cap measured at 202 ms worst
case (10.1% of the two-second interval) on the Java 25 reference run. Pending
indexes, deadline buckets, and query pages are consensus-bounded and tested at
their bounds; proof bundles are bounded by their enumerated fact sets. The
authenticated-map v1 wire, state, query, and proof-key contracts are hereby
frozen. The two deferrals are operational verifications that cannot change
the frozen contracts: the native-runtime measurement repeat
(`./gradlew :appchain-stdlib-contracts:benchmarkAuthenticatedMapAuthorizationCrypto`
on the native image) may only tighten documentation of the existing cap, and
console browser automation replaces nothing in the host-verified API
contracts. The Phase 4 Poseidon profile deferral is retained unchanged.
