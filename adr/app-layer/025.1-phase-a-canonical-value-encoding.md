# ADR-025.1 Phase A — canonical value encoding

Status: implemented and qualified on 2026-08-04.

## Contract freeze

Authenticated-map genesis codec version 2 adds `valueEncoding` as the final
field of every collection descriptor. The closed catalog is:

```text
0 = opaque
1 = canonical-cbor
```

The five-argument Java constructor remains source compatible and selects
`opaque`. Decoding is intentionally strict: codec-version-1 genesis bytes are
not reinterpreted with an implicit default. The regenerated genesis golden
vector and genesis id freeze the amended pre-release v1 contract; command,
entry, receipt, query, proof, and state-key encodings remain unchanged.

## Consensus behavior

Opaque values retain ADR-025 behavior. Canonical-CBOR collections accept one
complete RFC 8949 deterministic-CBOR item under fixed depth, item-count,
container-count, and collection byte limits. The bounded scanner rejects:

- non-preferred integer, length, simple, and floating-point encodings;
- indefinite items, tags, unsupported simple values, and trailing items;
- malformed UTF-8;
- duplicate or incorrectly ordered encoded map keys; and
- inputs exceeding the structural limits.

The encoding check runs after authorization and operation preconditions on
`PUT`, `PUT_IF_ABSENT`, `COMPARE_AND_SET`, and value-bearing `RESTORE` mutations.
It runs both during proposal validation and authoritative application. An
authoritative rejection produces `ERROR_VALUE_ENCODING = 10`; a batch remains
atomic. Genesis initial values pass through the same rule.

## Qualification

Coverage includes the canonical scalar, string, container, map-order, and
preferred-float corpus; malformed and adversarial inputs; the explicit opaque
compatibility path; typed receipts and atomic batches; and MPF replay across
restart, snapshot restore, and catch-up with canonical-CBOR values.

Primary verification commands:

```bash
./gradlew :appchain-stdlib-contracts:test :appchain-stdlib:test \
  --tests '*AuthenticatedMap*'
./gradlew :appchain-stdlib-contracts:verifyAuthenticatedMapGoldenVectors
```
