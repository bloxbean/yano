# ADR-025.1 Phase B — declarative schemas

Status: implemented and qualified on 2026-08-04.

## Contract freeze

Authenticated-map genesis codec version 3 adds:

- a canonically ordered, bounded `validators` catalog;
- `validatorId` on each collection descriptor; and
- the `ValidatorDescriptor` wire record in `appchain-stdlib-contracts`.

The schema kind inlines canonical `yano-cbor-schema-ir-v1` bytes, uses an empty
provider id and canonical empty parameter map, and requires its collection to
select canonical-CBOR value encoding. Validator ids are unique and every
descriptor must be referenced. Genesis construction validates initial values.
The schema fields alter canonical genesis bytes and `genesisId`; command, entry,
query, receipt, proof, and state-key encodings remain unchanged.

## Authoring and runtime

`AuthenticatedMapCddlCompiler` in devtools compiles the closed,
non-recursive `cddl-yano-subset-v1` before genesis. It supports exact text-keyed
maps, bounded arrays, named rules, the native CBOR integer domain, bounded text
and byte strings, booleans/null, literals, choices, ranges, optional fields, and
explicit occurrence bounds. It rejects external references, unbounded
occurrence, host regular expressions, generics, sockets, and unknown controls.

Consensus nodes do not parse CDDL. They strictly decode the inlined IR once at
startup and evaluate it through a total predicate with fixed schema-size,
node/depth, container, occurrence, and evaluation-step limits. Schema checks run
after authorization, transition preconditions, and canonical encoding in both
proposal validation and authoritative application. An authoritative rejection
uses `ERROR_VALUE_SCHEMA = 11`; batches remain atomic.

The published `schema-vectors.properties` corpus is compiled and evaluated by
both the Java implementation and an independent Python implementation. The
exact grammar and limits are published beside it as
`cddl-yano-subset-v1.md` in the contracts artifact.

## Determinism and startup gates

Coverage includes accepted/rejected conformance values, canonical IR ordering,
integer and structural boundaries, adversarial/malformed input, initial-entry
validation, typed receipts, atomic batches, schema-dependent genesis identity,
fail-closed startup on a mismatched schema genesis, and MPF replay across
multiple runs, restart, snapshot restore, and catch-up.

Primary verification commands:

```bash
./gradlew :appchain-stdlib-contracts:check :appchain-stdlib:test \
  :appchain-devtools:test
./gradlew :appchain-stdlib-contracts:benchmarkAuthenticatedMapSchema
```

The 2026-08-04 development-machine microbenchmark used 500,000 validations of
a representative exact product map after 20,000 warmups. Canonical encoding
alone measured 171.4 ns/value; canonical decode plus schema evaluation measured
509.4 ns/value (2.97× the encoding-only path). These are single-process,
in-memory observations, not production throughput or latency bounds; reproduce
them on the target hardware before selecting operational limits.
